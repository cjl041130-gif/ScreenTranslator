# ScreenTranslator v0.3.8 — 原文字号跟随

## 改动

- OCR 文字块保留原始单行高度和视觉行数。
- 段落合并时保留加权平均行高，避免多行段落按整个外框高度放大。
- 翻译覆盖层先按显示器 DPI 将物理像素换算为 WPF 设备无关像素，再计算字号。
- 标题、副标题使用半粗体；正文和小字保留对应的视觉层级。
- 字号仍受设置中的字体缩放控制，并保留可读的最小、最大边界。

## 自动验证

- 150% DPI：标题 40.5、正文 22.1、小字 12.3。
- 六行合并段落：字号保持为正文的 22.1，不使用 240 像素总外框高度。
- Phase 3 OCR、翻译、缓存、取消与段落合并测试全部通过。
- 30 秒 Windows Graphics Capture 回归通过，平均预览约 25.6 FPS，最低采样约 24.5 FPS。
- 8 次 Restart、Pause/Resume/Stop、125%/150%/175% DPI 布局均通过。

## 范围

未修改 Windows Graphics Capture、显示器枚举、帧资源所有权或捕获生命周期实现。
