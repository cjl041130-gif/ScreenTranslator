## 长期性能实测

600 秒真实桌面测试通过，原始记录位于 `docs/test-results/soak-10min/`。

| 指标 | 实测 |
|---|---:|
| 捕获分辨率 | 2560×1440 |
| 连续采样时长 | 600 秒 |
| 平均真实预览 FPS | 28.13 |
| 最低采样区间 FPS | 25.60 |
| 60–180 秒平均私有内存 | 275.4 MB |
| 最后 120 秒平均私有内存 | 278.3 MB |
| 两阶段平均私有内存差 | +2.9 MB |
| 首次/末次采样句柄 | 1289 / 1277 |

所有采样区间实际预览 FPS 均超过 20，进程私有内存呈平台波动，本次未发现明显持续内存泄漏。GPU 捕获服务日志通常接近目标 30 FPS；表内使用真正更新到 WPF 的预览帧率，口径更严格。

长测后增加了重复关闭保护和异常取帧释放范围修正，随后对最终源码执行独立短回归；这些修正没有改变正常捕获/复制/预览路径。最终短回归结果另存于 `docs/test-results/final-smoke/`。

最终短回归通过：20 秒平均预览 26.75 FPS，最低采样区间 26.10 FPS；启动、暂停、恢复、停止和 8 次重建全部通过。最终源码构建为 0 警告、0 错误。开发及测试于 2026-09-09 执行，交付收尾于 2026-09-10 完成。

## 解释与限制

- FPS 衡量实际新帧；静止画面 FPS 下降不是卡顿结论。本次使用持续变化的小窗口作为测试刺激。
- 内存验收观察真实进程 Private Bytes 和句柄，同时记录 Working Set 和托管内存；不调用强制 GC，不使用仅看托管堆的结论代替原生内存验证。
- 10 分钟无持续上涨只说明本次有限时间运行未发现明显泄漏；硬件热插拔和设备重置的错误路径另列为待测。
- 当前预览是 8 位 BGRA 的 SDR 调试画面；受保护内容与安全桌面不保证可捕获。
- 最终交付是便携发布包；没有安装器或商业代码签名。

## 本机兼容性发现

初版 Desktop Duplication 在本机返回 DXGI_ERROR_UNSUPPORTED，已移除并改用 WGC。受限开发进程无法访问系统捕获服务；在正常 Windows 桌面进程中 WGC 成功运行。用户应直接运行 Release 程序，无须为普通启动授予管理员权限。
