# ScreenTranslator｜屏幕与文档翻译

把屏幕上的英文内容变成易读的中文。ScreenTranslator 是一款 Windows 桌面应用，面向观看英文课件、演示文稿和文档的用户。你可以导入文档进行阅读翻译，也可以识别屏幕上的内容；界面提供原文与译文的阅读和显示方式。

> 项目使用 C# 和 WPF 开发。GitHub 页面显示的「C#」是开发语言统计，不代表需要会编程才能使用。

## 主要功能

- **屏幕实时识别**：选择显示器后手动开始，识别屏幕上的英文内容并展示中文结果；支持暂停、继续和停止。
- **演示文稿识别**：针对 WPS 演示文稿的编辑与放映场景识别页面区域，尽量避开菜单和周边窗口。
- **文档翻译**：从应用中导入支持的文档，在保留页面阅读体验的界面中查看原文与译文。当前文档入口支持 PDF、PPTX 和 DOCX；具体格式兼容性会受文件内容和 Office/WPS 版本影响。
- **多种翻译方式**：可选 DeepL，或 DeepSeek V4 Flash / V4 Pro。请在应用设置中填入对应服务的 API 密钥。
- **A/文品牌图标**：桌面应用与安装快捷方式使用统一图标。

## 下载与安装

前往 [Releases 下载页面](https://github.com/cjl041130-gif/ScreenTranslator/releases)，下载最新的 Windows x64 安装包（文件名通常以 .exe 结尾），运行安装程序并按提示完成安装。安装后可从开始菜单启动「屏幕翻译器」。

首次运行时，请在设置中配置所选翻译服务的 API 密钥。屏幕捕获与 OCR 在本机完成；启用 DeepL 或 DeepSeek 翻译时，识别出的文字会发送给你选择的服务进行翻译，因此需要网络连接，并受该服务的账号、隐私政策和计费规则约束。应用不会把屏幕截图上传作为翻译输入。

Windows 可能会对未经过商业代码签名的安装包显示安全提示。请确认安装包来自本项目的 Releases 页面后再继续。

## 快速开始

1. 安装并打开应用。应用启动时保持待机，不会自动捕获屏幕。
2. 进入首页或「实时识别」，选择要识别的显示器。
3. 在设置中选择 DeepL 或 DeepSeek 模型，并填入相应 API 密钥。
4. 点击「开始识别」，需要时暂停或停止；或者进入「文档翻译」导入文件。
5. 在显示设置中选择适合自己的译文呈现方式。

## 系统要求

- Windows 10（版本 2004 / build 19041）或更新版本；建议使用 Windows 11。
- 64 位 x64 电脑及支持 Windows Graphics Capture 的图形驱动。
- 屏幕识别需要处于已登录的 Windows 桌面会话；受保护内容、安全桌面或某些远程会话可能无法捕获。
- 在线翻译需要可用网络、服务账号和 API 密钥。屏幕捕获与本地 OCR 不需要网络。

## 隐私说明

屏幕图像和 OCR 识别在本机处理。选择在线翻译后，应用只需将识别文字发送给对应的翻译服务；请勿翻译你无权提交给第三方服务的敏感内容。API 密钥请仅保存在自己的本机设置中，不要提交到 GitHub，也不要在问题反馈中公开。

## 源码与开发

本项目是 C# / .NET 10 / WPF Windows 桌面应用。普通用户无需安装开发工具；开发者可安装 .NET 10 SDK，在仓库目录执行：

    dotnet restore .ScreenTranslator.sln --configfile .NuGet.Config --locked-mode
    dotnet build .ScreenTranslator.sln -c Release

项目结构按职责组织：

- App/：桌面界面、页面和 ViewModel。
- Capture/：显示器信息及 Windows Graphics Capture 屏幕捕获。
- Vision/、OCR/、Recognition/：页面区域分析、本机文字识别与识别流程。
- Document/：文档导入和预览。
- Translation/、Overlay/：翻译服务和译文显示。
- Installer/：Windows 安装包构建脚本。
- docs/：架构、测试和项目记录。

## 已知限制

- DeepL 与 DeepSeek 是在线翻译服务，不是离线模型；需要各自的 API 凭据，费用和可用地区由服务提供方决定。
- 屏幕 OCR、页面区域检测和文档渲染会受到字体、排版、遮挡、扫描质量及文件特性的影响；复杂文档可能需要人工校对。
- WPS 是主要实机演示环境。不同版本的 WPS、显卡驱动和 Windows 版本可能有不同表现。
- 本项目仍在持续开发中。请通过 Issues 提交可复现的问题，并注明 Windows 版本、应用版本及相关日志；不要附上密钥或敏感屏幕内容。
